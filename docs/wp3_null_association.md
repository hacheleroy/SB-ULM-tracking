# WP3 — Explicit null associations for missed detections and clutter

Benchmark date: 2026-10-19.

## Scope and scientific claim

This milestone is the smallest calibrated extension of the Option-A sampler.
The latent population still contains two persistent bubbles, but observation
cardinality may now change from frame to frame. For bubble (i) at time (t),
the association variable is:

\[
a_{t,i}\in\{-1,0,\ldots,M_t-1\}
\]

The value `-1` means that the bubble was not detected. Non-negative indices
must be injective within a frame, so two bubbles cannot use the same
localization. A detection index not used by any bubble is interpreted as a
false positive generated by clutter.

This is not yet a variable-latent-cardinality model. A run of null associations
does not mean that a bubble has died; its Matérn path still exists throughout
the sequence. Birth and death require a separate existence state and prior.

## Observation and association model

Each persistent bubble is detected independently with probability (p_D).
Clutter is a spatially uniform Poisson point process over a fixed region
(R), with expected count \(\lambda_c\) per frame and intensity
\(\kappa=\lambda_c/|R|\). Conditional on an association, every assigned
localization has the Gaussian localization model from WP2 and each coordinate
of each latent path has the calibrated Matérn-3/2 prior.

Let (n_A), (n_M), and (n_C) denote the total numbers of assigned target
detections, missed target detections, and unassigned clutter detections. After
integrating the continuous Matérn paths, the association density is:

\[
\begin{aligned}
p(Y,a)
&=e^{-T\lambda_c}
  p_D^{n_A}(1-p_D)^{n_M}\kappa^{n_C}\\
&\quad\times
  \prod_{i,d}
  \mathcal N\!\left(
    y_{a_i,d};0,
    K_{d,I_iI_i}+\sigma_{\mathrm{loc}}^2I
  \right)
\end{aligned}
\]

Here (I_i) contains only the times at which bubble (i) is assigned a
detection. A bubble with no observation in a set of frames is propagated by
its prior rather than being forced onto an observed point. No clutter
factorial appears because the implementation uses the Poisson point-process
finite-set density, not a density over an ordered clutter list. This is the
standard detection/missed-detection/Poisson-clutter structure used in Bayesian
multi-target tracking; see
[Mahler (2017)](https://arxiv.org/abs/1701.07078) and the overview of
[Bar-Shalom, Daum, and Huang (2009)](https://doi.org/10.1109/MCS.2009.934469).

Frame zero is conditioned to be complete and clutter-free, and its two
detections fix the otherwise arbitrary global particle labels. This anchor
isolates the new null/clutter difficulty from global label symmetry. It is a
calibration device, not an assumption intended for arbitrary in-vivo data.

## SMC construction and reversible moves

The normalized count-only model is used as the tractable SMC base density:

\[
q_0(a)\propto
p_D^{n_A}(1-p_D)^{n_M}\kappa^{n_C}
\]

The collapsed Matérn localization density is introduced by adaptive
tempering:

\[
\pi_\beta(a)\propto q_0(a)\,p(y_a\mid a)^\beta,
\qquad 0=\beta_0<\cdots<\beta_L=1
\]

The mutation kernel mixes two symmetric proposal types:

1. A whole-frame proposal replaces the current partial injection by a
   uniformly selected different valid partial injection. In one reversible
   move it can assign a bubble to null, reclaim a clutter point for a bubble,
   release an assigned point to clutter, or change an assignment.
2. A contiguous segment proposal swaps two particle labels over a selected
   time interval. It preserves coherent competing paths through a crossing.

The Metropolis ratio contains the count-density ratio and the tempered Matérn
likelihood ratio. Once \(\beta=1\), complete continuous paths are drawn exactly
from the Gaussian conditional distribution for the selected partial
association. The evidence estimator includes the analytically known
normalizer of the count-only base density and the Poisson void factor.

Exact enumeration is never called by the inference routine. It is used only
as an oracle on the small calibration problems.

## Calibration protocol

The primary gate uses five frames, two persistent bubbles, 5 µm localization
noise, a 6.84 mm/s Matérn velocity scale, 8,192 SMC particles, ten mutation
sweeps per temperature, ten additional final sweeps, and three independent
SMC seeds in each regime:

| Regime | Central separation | (p_D) | \(\lambda_c\) | Realized misses | Realized clutter | Exact support |
|---|---:|---:|---:|---:|---:|---:|
| Near clean | 20 µm | 0.95 | 0.05 | 0 | 0 | 2,401 |
| Missed detections | 0 µm | 0.70 | 0.05 | 4 | 0 | 63 |
| False positives | 0 µm | 0.95 | 0.75 | 0 | 2 | 8,281 |
| Joint corruption | 0 µm | 0.70 | 0.75 | 4 | 2 | 441 |

Every run must pass exact-target TV and JS thresholds calibrated against
equally sized exact posterior samples, 95% credible-set support and mass
checks, a 0.05 absolute-error ceiling for both null probabilities and expected
clutter counts, the continuous sliced-Wasserstein gate, and a 0.15-nat
absolute evidence-error ceiling.

The secondary map crosses (p_D\in\{0.65,0.80,0.95\}) with
\(\lambda_c\in\{0.05,0.35,0.75\}) over four independent data seeds. It uses
4,096 particles. For exact enumerability, this calibration simulator caps the
realized clutter at one point per non-anchor frame, giving a theoretical
support ceiling of \(13^4=28{,}561\). The largest support actually encountered
is 15,379. The inference density itself remains the stated, untruncated
Poisson model; the cap only selects tractable observed calibration sets.

## Results

All 12 primary runs pass every discrete, continuous, marginal, support, and
evidence check.

| Regime | Mean TV | Max-null error | Expected-clutter error | Path SW (µm) | Absolute evidence error (nat) |
|---|---:|---:|---:|---:|---:|
| Near clean | 0.00541 | 0.00332 | 0.00323 | 0.0867 | 0.0278 |
| Missed detections | 0.00761 | 0.00469 | 0.00051 | 0.0852 | 0.00622 |
| False positives | 0.03254 | 0.00138 | 0.00139 | 0.0907 | 0.0144 |
| Joint corruption | 0.01836 | 0.00755 | 0.00174 | 0.0808 | 0.0241 |

Across individual primary runs, the largest TV is 0.0343, the largest null
probability error is 0.00996, the largest expected-clutter error is 0.00525,
the largest path distance is 0.103 µm, the largest absolute evidence error is
0.0487 nat, and at least 99.22% of exact posterior mass is represented by the
sampled support. Adaptive tempering uses 8--13 stages.

On the 36-case map:

- TV, JS, exact posterior mass, null marginals, clutter marginals, and evidence
  pass in 36/36 cases;
- the maximum TV is 0.0862;
- the maximum null-probability and expected-clutter errors are 0.0172 and
  0.0123;
- every sample covers at least 96.37% of exact posterior mass;
- the largest absolute evidence error is 0.0885 nat;
- adaptive tempering uses 7--15 stages;
- the combined all-check count is 35/36 because one finite sample observes 85
  of the 86 states in the exact 95% credible set. It nevertheless covers
  98.62% of exact mass and passes every substantive marginal, distribution,
  and evidence check.

The last event is retained as a finite-sample support diagnostic rather than
hidden by another seed. Its scale is consistent with drawing only 4,096
particles from a posterior containing many low-mass states.

## Interpretation and remaining boundary

The result validates explicit null-association moves for the chosen
persistent-particle posterior. In particular, the sampler recovers not only
global association weights but also the per-particle probability of being
missed and the posterior expected number of clutter points. This is the
directly calibrable extension requested after the fixed-cardinality gate.

The result does not yet validate:

- births, deaths, or an unknown number of latent bubbles;
- removal of the complete first-frame anchor;
- inference of (p_D), \(\lambda_c\), or a non-uniform clutter field;
- more than two simultaneous latent bubbles or long sequences;
- real-data model fit, IQ/RF likelihoods, or ULMShare transfer.

The next representation must distinguish a temporarily missed persistent
bubble from a bubble that does not yet exist or has permanently left the field
of view. That requires explicit existence intervals (or a different
variable-mass representation) and a birth/death prior; it should not be
approximated by relabelling long runs of `-1` after sampling.

That extension is now implemented and calibrated as the separate WP4 model;
see `wp4_birth_death_slots.md`. WP3 remains the simpler persistent-particle
reference and is not retroactively reinterpreted as a birth/death model.

## Reproduction

To avoid BLAS thread oversubscription when using several worker processes:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
uv run python -m sbulm.wp3_null_calibration \
  --output-dir results \
  --n-particles 8192 \
  --n-smc-repeats 3 \
  --map-n-particles 4096 \
  --map-n-data-seeds 4 \
  --mh-sweeps 10 \
  --final-mh-sweeps 10 \
  --workers 6
```

The compact outputs are `wp3_null_calibration.json/.png` and
`wp3_null_calibration_map.csv/.png`. The JSON contains every target, threshold,
temperature, acceptance rate, finite-sample reference, and gate decision.
